# 模組 1：單機工作負載與健檢

## 問題與必要知識

在現有 VM 上，如何判斷計算工作能否啟動、能否寫入結果，失敗時能否指出原因？以實際工作需求辨認 CPU／記憶體、磁碟、程序限制與 cgroup、執行身分、逐層路徑權限、退出狀態和逾時。已有的 Linux 基礎直接使用，不另做假檔案或假目錄練習；不熟的機制才補概念和最小驗證。

## 實作與完成標準

在 `project/healthcheck/` 寫 Python CLI、使用說明與自動測試。輸入工作路徑和資源需求，輸出含證據的結構化結果，區分「條件符合」「條件不符」「無法判斷」；處理無效輸入、缺失路徑、拒絕存取與逾時，失敗要有非零退出狀態。使用可控的正常與失敗案例，不對現有機器施加高負載。能指出限制來自主機、程序、cgroup 或檔案路徑哪一層，而非把它們混為一談。Git 在真實程式需要版控時一起學。

第一次帶練前，先在本文件追加本次確定會用的 VM 指令、用途和檔案影響；取得輸出後再記錄結果。目前沒有假定本模組已完成。
