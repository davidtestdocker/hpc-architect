# 模組 2：單節點 Slurm

## 問題與必要知識

把一台 VM 變成可提交、觀察和診斷批次工作的單節點叢集。理解控制器、計算守護程序、驗證服務、分區與工作狀態如何配合；不只記命令名稱。

## 實作與完成標準

依 VM 的發行版與套件版本查對應文件，決定套件、服務帳號、MUNGE、Slurm 設定及 systemd 啟動順序。設定資源以實際 CPU／記憶體為準，保留系統開銷。提交互動與批次工作，核對等待／執行／完成／失敗狀態、執行位置、輸出與退出狀態。用可恢復的服務停止或設定錯誤案例練習從日誌定位問題；操作前確認沒有重要工作。

版本、設定、工作腳本和故障紀錄存入 `project/` 相應目錄。能從提交一路說明工作為何排到該節點、實際做了什麼、如何確認成功。遇到 pending、failed 或 drain 能用狀態和日誌區分原因。本模組只證明單節點。

開始帶練前，先在本文件追加確定的 VM 指令、用途與檔案影響；每次執行後補實際輸出及判讀。
