# 模組 3：C、MPI 與排程工作

## 問題與必要知識

交付不是只會印 `hello` 的計算工作：可編譯、有可核對的答案，能透過 Slurm 執行，並能解釋程序數、CPU 請求與執行位置。只補完成工作負載所需的 C 編譯、連結、陣列邊界和錯誤處理。

## 實作與完成標準

先寫序列基準，再寫 MPI 資料切分與結果合併，測試零筆、單筆、不可整除及一般輸入。理解 rank、communicator、集合通訊，以及 Slurm 的 `ntasks` 與 `cpus-per-task` 分別控制什麼。比較序列與 MPI 答案，記錄 rank 所在主機。跨節點結果等模組 4／5 有真實節點再驗證。

原始碼、編譯方式、測試輸入／預期輸出和 `sbatch` 腳本放在 `project/workloads/`。測試可重跑，MPI 答案與序列版一致；失敗時保留退出狀態。能區分「有多個 rank」「跨不同 VM」「有加速」三種主張。

開始帶練前，先在本文件追加本次 VM 指令、目的及檔案影響；執行後補實際結果。
