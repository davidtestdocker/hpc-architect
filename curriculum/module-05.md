# 模組 5：Ansible 可重建叢集

## 問題與必要知識

把手動成功的設定變成可審查、可重跑、可從乾淨環境重建的部署，而不是只有一份無法驗證的 playbook。

## 實作與完成標準

用 inventory、變數、模板、handlers 和 roles 表達節點角色、MUNGE、NFS、Slurm 及必要服務設定；秘密不入庫。部署前確認目標、版本和預期變更。先在可恢復的實驗節點測試：第一次部署後執行基本工作，第二次檢查非預期變更；節點暫時不可達或服務重啟後能安全重跑。人工前置步驟要如實列出。

`project/ansible/` 有可讀的部署程式與版本需求；`project/docs/` 有從乾淨 VM 重建的操作文件及實際結果。重建後控制器能看見至少兩個 compute，各節點能接受工作；重跑無未解釋變更。用工作輸出而非只有服務 active 證明功能。無多節點資源時交付縮小版並標明範圍。

開始帶練前，先在本文件追加本次 VM 指令、目的和要改的設定／服務；執行後補實際結果。
