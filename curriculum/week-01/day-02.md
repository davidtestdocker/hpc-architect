## 今日目標與課前筆記

昨天已完成 OS、CPU、記憶體、磁碟和網路盤點。今天確認使用者身分、目前工作目錄和基本工具位置，建立日後存放程式、設定與實驗資料的習慣。

## 學習順序

1. 逐條確認有效使用者、UID、群組和目前所在目錄。
2. 確認 home 目錄、PATH 與常用工具位置。
3. 建立後續實驗使用的非 root 工作目錄規劃；本日先不改動系統帳號或磁碟。

## 實作

先確認目前 root 帳號的 UID 與群組，再判斷是否已有適合日常操作的一般帳號。

## 實作紀錄

每條指令以「目的、重點輸出、結果解釋」追加在這裡。

### 1. 確認有效使用者與群組

**指令與目的**

```bash
id
```

確認目前 shell 的有效使用者、UID、主要群組與附加群組。

**重點輸出**

```text
uid=0(root) gid=0(root) groups=0(root) context=unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023
```

**結果解釋**

目前登入的是 `root`；UID 和主要群組 GID 均為 `0`，且只有 `root` 群組。SELinux context 顯示這個 shell 位於未受限制的 root 網域，對系統有完整權限；後續操作須格外確認目標與範圍。

### 2. 確認目前工作目錄

**指令與目的**

```bash
pwd
```

顯示目前 shell 的工作目錄，作為解讀相對路徑的基準。

**重點輸出**

```text
/root/hpc-arch
```

**結果解釋**

目前位於 root 家目錄下的課程工作區 `/root/hpc-arch`。之後在此 shell 使用相對路徑時，會以這個位置為起點。

### 3. 確認家目錄環境變數

**指令與目的**

```bash
printf '%s\n' "$HOME"
```

顯示目前使用者的家目錄環境變數。

**重點輸出**

```text
/root
```

**結果解釋**

`$HOME` 為 `/root`，與 root 帳號的家目錄一致；目前的課程工作區 `/root/hpc-arch` 位於其中。指令前的空白不影響 shell 執行。

### 4. 確認指令搜尋路徑

**指令與目的**

```bash
printf '%s\n' "$PATH"
```

顯示 shell 在輸入未含完整路徑的指令時，依序搜尋的目錄。

**重點輸出**

```text
/root/.local/bin:/root/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin
```

**結果解釋**

搜尋順序先包含 root 的個人工具目錄，接著是 `/usr/local`，最後是系統管理與一般系統指令目錄。若多個目錄有同名程式，會優先使用較前面的版本。

### 5. 確認 shell 工具位置

**指令與目的**

```bash
command -v bash
```

顯示目前 shell 解析 `bash` 時實際會使用的執行檔位置。

**重點輸出**

```text
/usr/bin/bash
```

**結果解釋**

`bash` 由 `/usr/bin/bash` 提供，而此目錄位於 `PATH` 中，因此可直接執行 `bash`。`command -v` 可用於確認工具是否存在及 shell 最終會選用的版本。

### 6. 確認 Python 直譯器位置

**指令與目的**

```bash
command -v python3
```

確認 Python 3 是否可由目前環境直接執行，並顯示其位置。

**重點輸出**

```text
/usr/bin/python3
```

**結果解釋**

系統提供的 Python 3 位於 `/usr/bin/python3`，可直接以 `python3` 執行，日後可用於資料處理與自動化腳本。

### 7. 確認 C 編譯器位置

**指令與目的**

```bash
command -v gcc
```

確認目前環境能否直接找到 C 編譯器 `gcc`。

**重點輸出**

```text
（無輸出）
```

**結果解釋**

目前 `PATH` 找不到 `gcc`，表示 C 編譯器尚未安裝或未加入搜尋路徑。今天僅盤點工具狀態，不安裝套件。

### 8. 列出本機帳號

**指令與目的**

```bash
getent passwd
```

查詢系統帳號資料庫，確認是否已有適合日常操作的一般使用者。

**重點輸出**

```text
a2264:x:1000:1005::/home/a2264:/bin/bash
```

**結果解釋**

除了 root 與多個使用 `nologin` 的系統服務帳號外，已存在一般帳號 `a2264`：UID 為 `1000`、家目錄為 `/home/a2264`，且可使用 `/bin/bash` 互動式登入。因此不需要建立新帳號；下一步只確認其群組歸屬。

### 9. 確認一般帳號的群組

**指令與目的**

```bash
id a2264
```

確認一般帳號 `a2264` 的 UID、主要群組與附加群組。

**重點輸出**

```text
uid=1000(a2264) gid=1005(a2264) groups=1005(a2264),4(adm),39(video),1000(google-sudoers),1001(dip),1002(docker),1003(lxd),1004(plugdev)
```

**結果解釋**

`a2264` 的主要群組為同名群組（GID `1005`），也加入了 `adm`、`video`、`docker`、`lxd`、`plugdev` 與 `google-sudoers` 等群組。其中 `google-sudoers`、`docker` 和 `lxd` 可能授予高度系統權限，因此日後不可將它們視為一般資料存取群組。帳號本身適合作為日常工作身分。

### 10. 確認一般帳號家目錄權限

**指令與目的**

```bash
ls -ld /home/a2264
```

確認 `a2264` 家目錄的擁有者與存取權限，作為後續非 root 工作區規劃的依據。

**重點輸出**

```text
drwx------. 6 a2264 a2264 147 Sep 23 11:11 /home/a2264
```

**結果解釋**

`/home/a2264` 由 `a2264:a2264` 擁有，權限為 `700`（`drwx------`），只有該帳號可讀、寫及進入。此家目錄適合作為日後非 root 實驗檔案的私人工作區；今天不建立目錄，也不變更帳號或權限。

### 11. 驗證切換至一般帳號的登入環境

**指令與目的**

```bash
sudo -iu a2264 pwd
```

以登入模式切換至 `a2264` 後顯示工作目錄，確認日後可使用此一般帳號進行實驗。

**重點輸出**

```text
/home/a2264
```

**結果解釋**

切換後工作目錄為 `/home/a2264`，證實可取得 `a2264` 的登入環境。後續實驗應優先使用此一般帳號及其家目錄；只有系統管理工作才使用 root。

```bash
date -u '+%F %T UTC'
```

以 UTC 記錄本日實作完成時間。

**重點輸出**

本日已完成使用者、目錄、權限、`PATH` 與基本工具位置的盤點，也確認日後可優先使用一般帳號 `a2264` 的家目錄進行實驗。
