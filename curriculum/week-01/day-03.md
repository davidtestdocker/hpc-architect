# W01 D3：終端機與路徑

狀態：已完成｜實際日期：2026-09-24｜完成時間：2026-09-24 03:14:23 UTC

## 今日目標與課前筆記

shell 解讀命令；絕對路徑從 / 開始，相對路徑由目前目錄開始。

## 學習方式

帶練時一次只執行一條指令；輸出確認後，再進到下一步。

## 實作

用 pwd、ls、cd、mkdir 建立練習目錄，離開再返回並解釋所在位置。


## 實作紀錄

帶練時追加實際命令、重點輸出與解釋。

### 1. 建立非 root 路徑練習目錄

**指令與目的**

```bash
sudo -iu a2264 mkdir -p /home/a2264/hpc-labs/path-practice
```

以一般帳號 `a2264` 建立今天的路徑練習目錄。

**重點輸出**

```text
（無輸出）
```

**結果解釋**

`mkdir -p` 成功建立 `/home/a2264/hpc-labs/path-practice`，並會一併建立不存在的父目錄；它可安全重複執行。練習目錄位於一般帳號的家目錄，而非 root 工作區。

### 2. 檢查練習目錄的擁有者與權限

**指令與目的**

```bash
ls -ld /home/a2264/hpc-labs/path-practice
```

確認新目錄的擁有者與權限。

**重點輸出**

```text
drwxr-xr-x. 2 a2264 a2264 6 Sep 24 03:06 /home/a2264/hpc-labs/path-practice
```

**結果解釋**

目錄由 `a2264:a2264` 擁有，權限為 `755`：`a2264` 可讀、寫及進入，其他使用者可讀及進入但不能修改。這是使用者自有練習目錄可用的預設權限。

### 3. 進入一般帳號的登入 shell

**指令與目的**

```bash
sudo -iu a2264
```

開啟 `a2264` 的登入 shell，讓後續路徑操作在非 root 環境進行。

**重點輸出**

```text
[a2264@instance-20260923-104239 ~]
```

**結果解釋**

提示字元變為 `a2264`，代表目前 shell 已切換到一般帳號；`~` 代表其家目錄 `/home/a2264`。此切換只影響目前終端機工作階段，離開後會回到 root shell。

### 4. 以相對路徑進入練習目錄

**指令與目的**

```bash
cd hpc-labs/path-practice
```

從家目錄使用相對路徑切換至練習目錄。

**重點輸出**

```text
[a2264@instance-20260923-104239 path-practice]$
```

**結果解釋**

相對路徑 `hpc-labs/path-practice` 是以原本的家目錄 `/home/a2264` 為起點。提示字元最後一段變為 `path-practice`，表示目前已進入目標目錄；下一步以 `pwd` 顯示完整絕對路徑。

### 5. 顯示目前位置的絕對路徑

**指令與目的**

```bash
pwd
```

確認切換後的完整工作目錄。

**重點輸出**

```text
/home/a2264/hpc-labs/path-practice
```

**結果解釋**

`pwd` 顯示從根目錄 `/` 開始的絕對路徑，因此不依賴目前所在位置。它確認剛才的相對路徑是以 `/home/a2264` 為起點解析為此目錄。

### 6. 列出新目錄的內容

**指令與目的**

```bash
ls -la
```

以詳細格式列出目前目錄的所有項目，包括以點開頭的特殊目錄。

**重點輸出**

```text
total 0
drwxr-xr-x. 2 a2264 a2264  6 Sep 24 03:06 .
drwxr-xr-x. 3 a2264 a2264 27 Sep 24 03:06 ..
```

**結果解釋**

新目錄沒有一般檔案。`.` 代表目前目錄，`..` 代表父目錄 `/home/a2264/hpc-labs`；`-a` 使這些以點開頭的特殊項目顯示，`-l` 則顯示權限與擁有者。

### 7. 使用父目錄相對路徑離開

**指令與目的**

```bash
cd ..
```

使用 `..` 從目前目錄移至上一層。

**重點輸出**

```text
[a2264@instance-20260923-104239 hpc-labs]$
```

**結果解釋**

`..` 代表父目錄；提示字元變為 `hpc-labs`，確認目前已由 `path-practice` 上移至 `/home/a2264/hpc-labs`。

### 8. 以相對路徑返回練習目錄

**指令與目的**

```bash
cd path-practice
```

從父目錄使用相對路徑返回今天的練習目錄。

**重點輸出**

```text
[a2264@instance-20260923-104239 path-practice]$
```

**結果解釋**

目前位於 `/home/a2264/hpc-labs` 時，`path-practice` 會解析為其子目錄 `/home/a2264/hpc-labs/path-practice`。提示字元確認已成功返回。

### 9. 記錄完成時間

**指令與目的**

```bash
date -u '+%F %T UTC'
```

以 UTC 記錄本日實作完成時間。

**重點輸出**

```text
2026-09-24 03:14:23 UTC
```

**結果解釋**

本日已以一般帳號完成練習目錄的建立、查看、離開與返回，並驗證絕對路徑、相對路徑及父目錄 `..` 的行為。
